Smart assignment

The nearest free rider.
Every time.

When an order lands, Dispatchly searches outward from the restaurant, picks the closest rider who is free and locks them in.

Real distance, fast
PostGIS searches a spatial index instead of checking every rider one by one.
One rider, one order
Row-level locking means two orders landing at the same moment can’t grab the same person.
Automatic reassignment
If a rider declines or drops offline, the order goes straight to the next nearest.

Tech specs

Backend
ASP.NET Core Web API on .NET 10, C#, Entity Framework Core
Frontend
Angular 22, TypeScript, MapLibre GL vector maps
Database
PostgreSQL 17 with PostGIS for spatial search
Real time
SignalR pushes every rider’s position every 2 seconds
Live state
Redis holds the latest position of every rider
Routing
OSRM on OpenStreetMap roads for routes and ETAs
Quality
xUnit tests, GitHub Actions CI, k6 load tests
Runs on
Docker Compose: API, web app, database, cache and router
